# Weather App
 A minimalist and modern weather application that provides real-time weather updates for any city.
## About the Project
This project was created as a part of my journey to understand how JavaScript interacts with external data sources (APIs).
* **Process Learning**: I learned how to register and implement the OpenWeatherMap API. I utilized AI as a supportive learning tool to clarify complex concepts like asynchronous logic (async/await) and to help debug specific CSS layout challenges.
* **Design Concept**: The user interface is designed following the Neumorphism (Soft UI) style, focusing on using box-shadow to create realistic depth and "sunken/raised" effects for the components.
## Technologies Used
* **HTML5**: For building the structure of the search bar and weather information blocks.
* **CSS3**:
             Used Flexbox for a balanced and centered layout.
            Applied Linear Gradients for the background and specific shadowing techniques for the Neumorphism effect.
            Used Transitions to create a smooth feedback feel during user interaction.

* **JavaScript**:
 Used Fetch API to retrieve real-time data from the server.
 DOM Manipulation to dynamically update temperature, humidity, and wind speed without reloading the page.
